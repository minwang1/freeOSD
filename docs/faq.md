# 常见问题（FAQ）

## 色彩预设已应用，但画面色温没有变化

部分显示器在 **sRGB、Display P3、DCI-P3、Adobe RGB** 等受限色彩模式下，会锁定色温、白点、RGB 增益或其他画面参数。这是显示器固件的模式限制：DDC/CI 仍可能接受色彩预设写入，并在读回时返回新的 VCP 值，但显示器不会把该设置反映到当前画面。

可以按以下步骤确认：

1. 打开显示器 OSD，查看当前色彩模式是否为 sRGB、P3 或其他锁定模式。
2. 切换到 Standard、User、Custom 或显示器提供的可调模式。
3. 再应用色彩预设，观察 OSD 模式及画面变化。
4. 若仍无变化，查看 `%LOCALAPPDATA%\MonitorControl\Logs\monitor-control.log` 中 `code=0x14` 的写入和读回记录。写入及读回成功只能确认显示器报告的 VCP 值已更改，不能单独证明面板画面处理已应用；最终效果还取决于显示器固件、当前图像模式和连接链路。

有些显示器会在切换色彩模式时重置或忽略色温设置。此时请以显示器 OSD 和实际画面为准，并检查该模式下是否允许调整色温或 RGB 增益。

## 亮度、对比度或 RGB 增益无法调整

显示器当前图像模式可能会锁定相应控件。请在 OSD 中切换到 Standard、User 或 Custom 等可调模式后重试。设备支持哪些控制也会受显示器固件、DDC/CI 开关和连接链路影响。

## DDC/CI 控制无响应

确认显示器 OSD 中已启用 DDC/CI，并检查显卡、转接器、扩展坞或 KVM 是否透传 DDC/CI。查看本地诊断日志中的操作结果；日志写入成功不等于显示器一定产生可见效果，必要时用 OSD 进行交叉确认。
